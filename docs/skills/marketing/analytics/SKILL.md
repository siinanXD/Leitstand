# Analytics

- Eingabe: Besuche, Demo-Anfragen, Abbrüche der letzten 7 Tage aus PostHog. Fehlen sie, steht im Ergebnis „keine Kennzahlen“, es werden keine Zahlen erfunden.
- Rechne Anfragen pro Besuch und nenne die größte Abbruchstelle. Daraus folgt der Schwerpunkt der Woche (Landing-Page, Anzeige oder Lead-Magnet).
- Wenige Besuche (unter etwa 100) beweisen nichts: Trend nennen, nicht Ursache.
- UTM-Parameter nach festem Schema `utm_source=<plattform>&utm_medium=<anzeige|beitrag>&utm_campaign=<produkt>-<woche>`, damit die nächste Woche vergleichen kann.
