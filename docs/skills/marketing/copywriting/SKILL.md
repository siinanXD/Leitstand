# Copywriting

- Aufbau: Problem der Rolle, Lösung in einem Satz, drei Nutzen, ein Beleg, eine Handlung.
- Du-Ansprache nur, wenn das Produkt sie nutzt; sonst Sie. Kurze Sätze, Verben, keine Floskeln („innovativ“, „ganzheitlich“).
- Belege nur aus echten Daten oder aus `docs/PRODUCT.md`. Sonst „[prüfen]“ statt Behauptung.
- Mit KI erstellte Texte tragen die Kennzeichnung „mit KI erstellt“; Sinan gibt jeden Text frei.
