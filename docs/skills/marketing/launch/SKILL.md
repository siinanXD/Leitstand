# Launch

- Anlass sind gemergte, für Nutzer sichtbare Funktionen (Quelle: Feature-Agent, nicht erfunden).
- Der Metricool-Entwurf ist ein Beitrag: Nutzen in einem Satz, ein Bild oder Clip, eine Handlung, Link mit UTM.
- Angelegt wird er nur mit `createScheduledPostForReview`. Nie direkt posten, nie ohne Freigabe.
- Beste Zeit nennt Metricool; der Agent schlägt sie nur vor.
