# Ad-Creative

- Google: Überschrift ≤ 30 Zeichen, Beschreibung ≤ 90. Meta: erster Satz trägt, Rest wird abgeschnitten. LinkedIn: Überschrift ≤ 70.
- Eine Aussage pro Anzeige: Nutzen für die Rolle (Ausbilder spart Zeit, Azubi besteht die IHK-Prüfung), dann eine Handlung („Demo anfragen“).
- Konkret statt groß: „Lernstand je Azubi auf einen Blick“ statt „revolutionär“.
- Keine Garantien („100 % bestanden“), keine erfundenen Zahlen, keine Kundenstimmen ohne Beleg.
- Pro Plattform eine Variante; spätere Tests liefert `analytics`.
