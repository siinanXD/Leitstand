# Conversion-Optimierung

- Je Lauf ein Landing-Page-Vorschlag: Überschrift, Unterzeile, drei Nutzen, ein Beleg, ein Formular, ein Knopf. Nicht die ganze Seite neu.
- Ein Ziel pro Seite (Demo-Anfrage). Keine zweite Handlung daneben.
- Setze bei der größten Abbruchstelle aus `analytics` an. Ohne Daten: Überschrift und Formularlänge zuerst.
- Formular so kurz wie möglich. Handy zuerst; Ziele ≥ 44 px, Kontrast ≥ 4,5:1 (gilt auch für Werbeseiten).
- Vorschlag als Text; umgesetzt wird er in einem eigenen PR nach Freigabe.
