# SIN-832: Pilot für den ereignisgesteuerten Codex-Worker

Linear: https://linear.app/sinan-kahraman/issue/SIN-832

## Auftrag

Dieser Draft-PR ist eine Übergabe an den ChatGPT/Codex-Worker. Die neue GitHub-Event-Automation reagiert auf offene Draft-PRs von siinanXD im Leitstand-Repo mit `[codex-worker]` im Titel. Die produktive Dispatcher-Auswahl wird durch diesen Pilot noch nicht geändert.

Erstelle `docs/CODEX-WORKER.md` mit Trigger, erlaubtem Auftragsformat, Claim/Completion-Markern, genau einem Implementierer je Issue, Tests/PR-Rückmeldung und Blocker-Regeln. Ergänze einen kurzen Verweis in `AGENTS.md`, damit vorhandene Agenten diesen Übergabeweg finden und risikoarme Aufgaben selbst übergeben können. Keine Erweiterung von Rechten, Tools, Secrets oder Merge-Gates.

## Fertig, wenn

- [ ] Übergabeprotokoll beschreibt Draft-PR, Titelmarker, Branche, Linear-ID und Briefdatei eindeutig.
- [ ] AGENTS.md verweist auf das Protokoll und verhindert konkurrierende Umsetzung durch Claude/Codex.
- [ ] Bei Start wird ein Claim mit Start-Commit im PR dokumentiert, bei Abschluss ein Completion-Marker mit Prüfergebnissen.
- [ ] Bestehende Regeln für Secrets, Infisical-Pause und Security-/Produktionsfreigaben bleiben erhalten.
- [ ] Erforderliche Repo-Checks erfolgreich; keine Live-Trigger-Bestätigung aus bloßer Konfiguration ableiten.
- [ ] Ergebnis in SIN-832, SIN-611 und gedaechtnis; PR ready, kein eigener Merge.

## Nicht Teil des Pilots

Kein neues Agentenframework, keine neuen kostenpflichtigen API-Aufrufe, kein produktiver Dispatcher-Umbau. Dass der Worker automatisch auf dieses Ereignis reagiert hat, muss durch seinen tatsächlichen Start-/Ergebnisbeleg separat bestätigt werden. Ein manueller Bearbeiter darf diesen Nachweis nicht vortäuschen.
